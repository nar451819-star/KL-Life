KL V2.0

本版已完成：
- 首页“今天”卡片：自己写优先，未写时系统根据当天记录自动生成
- 四个模块：工作、财务、学习、Life
- 首页下方月历
- 月历显示当天美甲总金额，不显示人数
- 工作记录仅包含：开始时间、结束时间、金额、是否指名
- 交通费规则：当天最早开始至最晚结束达到8小时，自动增加418日元
- 自动计算营业额、客数、指名数、工资、出勤跨度、实际工作时间
- 财务、学习、Life及数据备份恢复
- 兼容旧版浏览器数据

上传方式：
解压后，将全部文件覆盖上传到 GitHub 的 KL-Life 仓库。
Cloudflare Pages 会自动更新 kl-life.pages.dev。
